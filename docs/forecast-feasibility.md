# 未来路况预测权限验证与替代方案

本文保留历史核验事实；项目范围已于 2026-09-29 更新，不再计划接入预测 API。

核验日期：2026-09-17。结论：现有高德 Key 无 ETD 权限；普通驾车接口正常。本次未找到已核实可由个人直接免费接入、满足本项目完整需求的未来预测 API。

## 实测记录

北京时间 2026-09-17 16:57，使用项目 `.env` 中已有 Key、配置中的深圳西丽到衡阳起终点，向 `/v4/etd/driving` 发出一次请求。出发时间设为请求时刻后 24 小时，`count=1`、`interval=1800`、`strategy=1`，在文档规定范围内。

结果为 HTTP 200，业务错误 `errcode=10012`、`errmsg=INSUFFICIENT_PRIVILEGES`，未返回预测数据。

随后用同一 Key 对 `/v3/direction/driving` 做一次对照请求，返回 `status=1`、`info=OK`、`infocode=10000`。据此确认当前 Key 有效，ETD 权限未开通。两次请求均未写入正式采样历史或触发通知。

脱敏结果保存于 [etd-permission-check.json](etd-permission-check.json)，其中不含 Key。实测证明当前 Key 的能力，不据此推断账号认证身份。

[高德官方高级路径规划文档](https://lbs.amap.com/api/webservice/guide/api-advanced/advanced-path)明确服务目前只向企业开发者开放。因此按当前公开规则，个人开发者不能把此接口作为可直接开通使用的基础能力。旧版 SDK 公告存在 ETD 功能，不足以证明目前个人有对应权限。

## 替代方案比较

| 方案 | 已核实能力与限制 | 对项目的决定 |
|---|---|---|
| 高德普通驾车 + 现有采样 | 对照请求成功，支持当前路线估算；当前项目已有采样与趋势链 | 继续使用，承接当前走廊比较与趋势 |
| 百度未来驾车 API | 官方支持未来 7 天，属于高级付费能力；有申请试用流程 | 可作为商务核验候选，不能宣称个人免费可用 |
| 腾讯未来 ETA | 本次官方文档页面未成功加载，未核实个人资格、价格和实际能力 | 保留待核验，不作为已验证替代方案 |
| 滴图路径规划 API | 官方文档有 `departure_time`，未在已读文档确认预测范围、节假日模型及个人权限 | 仅是候选线索，不能凭参数名认定等价于 ETD |
| 手动录入预测记录 | 可设计为导入用户实际查到的路线、出发时间、预测耗时及来源 | 适合少量候选，不依赖批量预测 API；预测来源本身仍需实际确认 |
| 自建历史参考 | 现有采样可描述已观察日期、时段与路线差异 | 能做历史路线时间图，无法保证未来国庆预测精度 |

百度依据：

- [未来驾车路线规划](https://lbsyun.baidu.com/docs/webapi?title=directionv2%2Fwebservice-direction-time)：`departure_time` 是高级付费服务，需联系工作人员开通。
- [地图高级服务](https://lbs.baidu.com/cashier/service)：提供工单申请、试用权限、试用后付费接入流程。
- [驾车路线规划](https://lbs.baidu.com/docs/webapi?title=directionv2%2Fwebservice-direction%2Fdirve)：路线请求提供途经点与未来时间相关能力，但二者联用的限制仍应在获得权限后实测。

滴图依据：[路径规划 API](https://lbs.xiaojukeji.com/docs/web/guide/%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92.html)。腾讯的代理商说明未作为技术结论依据。

## 历史建议（已由 2026-09-29 决定更新）

1. 保留四条走廊去返方向的 30 分钟采样，显示最新预计耗时、近几个小时变化和数据新鲜度。
2. 建立分场景历史路线时间图，明确标题是“历史采样参考”；中秋、节前、国庆和调休分别查看。
3. 路线与时间矩阵仅用于手动记录比较，未录入处留空，不预留预测接口。
4. 可增加手动录入入口，先比较用户实际关注的 2–3 条走廊与少量出发时间。每条记录包含来源、查询时间、预计出发时间、道路摘要和耗时；无法确认路线身份的记录不归入固定走廊。
5. 如果用户所用地图 App 实际提供该路线的未来出发时间查询，可把其可见结果手动录入。此工作流是建议设计，本次未验证用户手机 App 的入口、覆盖范围或结果，也未自动抓取 App。

该版本可以帮助筛选路线和复核出发前路况，但不能完整自动回答每个未来时刻的四走廊预测耗时。普通日期历史不能直接替代未来国庆预测。

## 2026-09-29 范围决定

用户已确认保留自动采样与手动预测记录，不预留预测接口。上文供应商比较是 2026-09-17 的调查记录，不代表后续接入计划。停止将供应商试用、商务开通和自动预测适配列入开发阶段，后续以 [项目重规划 v2](project-plan-v2.md) 为准。
