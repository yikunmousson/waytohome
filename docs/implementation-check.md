# 自动采样与手动记录版本验收

日期：2026-09-29。范围：本地实现与测试，未发布线上。

## 实现

- 保留原有采样频率和四走廊双向采集，增加日历场景标签。
- 历史图支持场景筛选和各走廊样本、日期、小时覆盖统计；分段历史比较按场景隔离。
- 默认分析不再生成经验预测窗口，首页改为手动方案录入、比较和矩阵。
- 手动记录在浏览器本地保存，支持编辑、删除、JSON 导入预览及冲突处理、导出备份。
- 条件包含出发时间范围、最晚抵达、休息时长和查询有效期；未来查询、过去出发、待核验和过期记录不排名。
- 浏览器检查自动采样有效期，采集停跑后不会持续把旧结果当作当前排名。
- 未增加预测 API、服务适配层或开通权限入口。

## 使用限制

手动记录不会跨设备同步；清除浏览器站点数据前需导出备份。测试示例只保存在临时测试浏览器，未写入正式采样。当前历史数据仍稀疏，不能据此承诺未来假期耗时。去程本轮道路序列变化提示已保留，需要核对实际走向。
