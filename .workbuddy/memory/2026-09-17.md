## 四条走廊的静态地图缩略图（新功能）

用户要「4 条流线的地图简易缩略图预览」。落地为 `src/thumb_map.py` + 看板新卡片。

**方案**：高德静态图 API（`v3/staticmap`），一次请求把 4 条折线画在同一张底图上。
`paths` 参数上限恰好是 **4 条**，与候选走廊数量一致 —— 四条共用一个 bbox、一个 zoom，
分叉关系才看得出来。产 `web/corridors-thumb-<方向>-v<route_version>.{png,json}`。

**为什么不用前端地图 SDK**：这是自己看的看板，静态 PNG 最省事，而且前端零 Key
（前端放 Key 会被抓走）。Key 只出现在本机脚本发出的服务端请求里。

### 踩到的坑（都写进 SKILL.md 了）

1. **`labels` 的文案里不能有空格**。`深圳·西丽地铁站` → OK；`深圳 · 西丽地铁站` →
   整条请求 `INVALID_PARAMS`。排查方式是逐项二分（先只给 paths，再逐个加 markers/labels）。
   解法：`clean_label()` 把空白全部抹掉，并收进 15 字上限。
2. **`paths` 的 `fillcolor`/`fillTransparency` 必须留空**（写成 `6,0x1F5FA8,0.95,,`）。
   少这两个逗号会报 `UNKNOWN_ERROR`(20003)；给了填充色则折线会闭合成多边形。
3. **`markers` 的 label 不能为空**（`mid,0x1D9E75:loc` → 20003）。
4. **`location`/`zoom` 在只给覆盖物时确实可省略**（自动适配 bbox），实测通过。
5. **高德 zoom 是整数，没法靠微调 bbox 加内边距**。四条走廊是南北向细长条，
   按 bbox 比例出图 = 407×1024，横向只剩 32 px 余量，而起点深圳正好压在 bbox 右下角，
   地名标签被画布边缘裁掉。解法：强制画布最小宽高比 1:2（512×1024），左右余量拉到 85 px。
6. **缩略图文件名要带 `route_version`**。上午的版本是「前端发现路线刚升级就不显示图」，
   但文件名没变，前端只能靠 `coverage.records === 0` 猜 —— 结果新版几何明明已经抓好、
   图也出好了，卡片仍然显示「等待首次采集」。改成把版本编进文件名
   （`corridors-thumb-outbound-v2.png`）：对不上就是 404 → 前端自然走降级提示，
   既不会「旧图配新数据」，也不用多一次 fetch。旧版本文件出图后自动清掉。

### 其它设计

- 几何缓存在 `data/geometry/<方向>.json`；路不会动，只在 `--refresh` 时重抓。
  缓存按 `route_version` + `waypoints` 校验，改了 config 会自动失效重抓。
- `--if-stale`：几何没变且图已存在就跳过下载，避免定时任务每 15 分钟白耗静态图配额。
- `decimate()`：自适应 Douglas-Peucker，每条线抽到 ~50 点（URL 约 4.4 K 字符）。
